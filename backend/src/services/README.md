# Services Directory

This directory contains business logic and domain services for the Fleet Tracking and Logistics platform.
Modules to be implemented in subsequent phases:
- `fleetService.js`: Vehicle management, assignments, and status updates
- `trackingService.js`: Ingestion and broadcasting of live GPS/telemetry coordinates
- `shipmentService.js`: Lifecycle of shipments, ETA calculations, and dispatch
- `alertService.js`: Threshold monitoring (speed, geofence, temperature, maintenance)
- `analyticsService.js`: Aggregated fleet metrics, fuel efficiency, mileage calculations
